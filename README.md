# Popeye Share Print

Popeye Share Print by Popeyemarketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa794ee9403bc029745977c/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye Share Print** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa794ee9403bc029745977c/releases/latest) and reinstall.
